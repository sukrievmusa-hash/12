# Сынақ — пробный ЕНТ по математике и физике

Статический сайт (GitHub Pages): 40 заданий в формате профильного предмета ЕНТ, 50 баллов, таймер, разбор, история результатов.

- `js/gen.js` — генераторы оригинальных заданий. Вариант = seed, поэтому вариант N всегда одинаковый, а «Случайный» каждый раз новый.
- `js/config.js` — цена, Kaspi, WhatsApp, число вариантов, бесплатные варианты, хэши кодов доступа.
- `js/app.js` — интерфейс.

Коды доступа в репозитории не хранятся, здесь только их хэши. Список кодов есть только у владельца.
