# Сынақ — пробный ЕНТ по профильным предметам

Статический сайт (GitHub Pages): 6 предметов — математика, физика, информатика, химия, биология, география. В каждом варианте 40 заданий в формате профильного предмета ЕНТ, 50 баллов, таймер, разбор, история результатов.

- `js/gen.js` — движок и генераторы заданий по математике и физике. Вариант = seed, поэтому вариант N всегда одинаковый, а «Случайный» каждый раз новый.
- `js/s-inf.js`, `js/s-chem.js`, `js/s-bio.js`, `js/s-geo.js` — информатика, химия, биология, география. Расчётные задачи генерируются, теоретические вопросы берутся из банков: в варианте N из каждого банка берётся свой вопрос по кругу.
- `js/config.js` — цена, Kaspi, WhatsApp, число вариантов, бесплатные варианты, хэши кодов доступа.
- `js/app.js` — интерфейс.
- `js/boss.js`, `js/boss-art.js`, `css/boss.css` — «Битва с боссами» (#/boss): 6 боссов по предметам + финальный «Хронос ЕНТ» (открывается после 3 побед). Бой — 2D-схватка сбоку: батыр игрока и босс упёрлись друг в друга, босс всё время давит. Верный ответ даёт батыру силу (3 уровня) и толчок с уроном, ошибка — рывок босса. Вытолкнули батыра за край — минус сердце, босса — «ринг-аут» и большой урон. Вопросы берутся из тех же генераторов, ошибки идут в статистику слабых тем. Бесплатно для всех. Бой = билет из 25 вопросов по уровням (12 лёгких, 8 средних, 5 сложных с выбором нескольких ответов), от лёгких к сложным; за сложные урон больше. При ошибке показывается верный ответ и через 2 с открывается следующий вопрос. На телефоне арена закреплена вверху экрана.
- Рейд с друзьями (#/raid/<код>): комната по ссылке, у каждого свои задания, урон складывается, здоровье босса растёт с числом игроков, 4 минуты на бой, в конце таблица и MVP. Связь — публичные MQTT-брокеры по WebSocket (подключение сразу ко всем, дубли отбрасываются) (список можно задать в `raidBrokers` в `js/config.js`), своего сервера не нужно.

Чтобы добавить вопрос, допишите строку в нужный банк: `['Вопрос', 'верный ответ', 'неверный 1', 'неверный 2', 'неверный 3', 'Разбор']`.

Коды доступа в репозитории не хранятся, здесь только их хэши. Список кодов есть только у владельца.
